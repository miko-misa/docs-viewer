# (sec-intro)= ようこそ Docs Viewer へ

Docs Viewer は、拡張 Markdown と Typst 数式、参照プレビューなどのリッチな機能を備えたドキュメントビューアです。このページでは、利用できる記法と UI 機能を「ユーザー向け仕様書」としてまとめます。記法は実際のレンダリングとともに紹介するので、必要に応じてこのページをテンプレートとして複製してください。

## (sec-frontmatter)= フロントマター

各 Markdown ファイルの先頭に YAML フロントマターを記述できます。タイトルやタグを設定すると、ページ上部のヘッダーやタグ表示に反映されます。

```md
---
title: "Docs Viewer チュートリアル"
tags:
  - guide
  - features
---
```

- `title` は DocHeader に表示されます。
- `tags` は単独ページでのみ利用され、複数指定が可能です。
- グループ化されたページの場合は、ディレクトリの `config.yaml` に定義した `tags` が優先されます。

## (sec-headings)= 見出しと TOC

見出しは通常の Markdown 構文に加えて、先頭に `(label-id)=` を書くことでラベルを付与できます。ラベルは参照用のアンカーとして機能します。

```md
## (sec-headings)= 見出しと TOC
```

ページ右側の TOC（Table of Contents）は H1〜H3 に加え、後述の `:::column-toc` で作成した見出し付きコラムも表示します。TOC はスクロール位置に追従し、クリックすると本文がスムーズにスクロールします。

### (sec-references)= ラベル参照の書き方

`@label-id` でラベルへリンクできます。リンクテキストを任意の文字列にしたい場合は `[任意の文字](@label-id)` と書きます。

- ラベルだけ: 参照先は [見出しと TOC](@sec-headings) を参照してください。
- 任意の文字列: [詳細はこちら](@sec-frontmatter)

リンクをクリックすると、小窓で該当箇所のプレビューを表示します。プレビュー表示モードはヘッダー右上のメニューから「フローティング」「インライン」を切り替え可能です。

## (sec-typst)= Typst 数式

Docs Viewer は Typst ベースの数式レンダリングに対応しています。インラインとブロックの両方が利用可能です。

- インライン: $a^2 + b^2 = c^2$
- ブロック:

$$
\int_0^\infty e^{-x^2} \dif x = \frac{\sqrt{\pi}}{2}
$$

数式にラベルを付けたい場合は `(eq-example)=` のように書き、`@eq-example` で参照できます。

## (sec-columns)= コラムディレクティブ

定理や注意事項などを強調したい場合は `:::column` を使います。メタ情報を `@title:` や `@background:` で指定すると、スタイル付きのコンテナとして表示されます。

```md
:::column
@title: コラムの基本
@background: #eff6ff
@border-color: #2563eb

コンテンツをここに記述します。
:::
```

実際のレンダリング:

:::column
@title: コラムの基本
@background: #eff6ff
@border-color: #2563eb

コンテンツの先頭に書いたメタ情報は自動的に取り除かれ、`DirectiveWrapper` が背景色やボーダーを適用します。
:::

### (sec-column-toc)= TOC に表示するコラム

`:::column-toc` を利用すると、コラム自体が TOC に見出しレベル 4 として表示されます。タイトルは必須です。

:::column-toc
(col-toc)=
@title: TOC に載るコラム
@background: #fef3c7
@border-color: #d97706

このコラムは TOC に表示され、クリックすると本文内の位置へスクロールします。参照リンクとしても [利用可能](@col-toc) です。
:::

### (sec-column-options)= 折りたたみと詳細設定

コンテンツが `50vh` を超えると、自動的に折りたたみボタンが表示されます。デフォルト値は以下の通りです。

| メタキー | デフォルト | 説明 |
| --- | --- | --- |
| `@title` | なし | 指定するとタイトル帯が表示される |
| `@color` | `#cbd5e1` | タイトル帯の背景色 |
| `@title-color` | `#1f2937` | タイトルテキスト色 |
| `@background` | 透過 | コンテンツ背景色 |
| `@border-color` | `#cbd5e1`（タイトルありの場合） | ボーダー色 |
| `@border-width` | `2px` | ボーダーの幅 |
| `@border-style` | `solid` | ボーダーのスタイル |

## (sec-annotations)= 注釈

長文の補足は `:::annotation` で記述します。本文中には上付き数字のマーカーが残り、ページ末尾に注釈一覧が自動生成されます。

例: この文は注釈で詳しく説明します。:::annotation
注釈内では段落や箇条書き、Typst 数式などのブロック要素も利用できます。

- 目的: 本文をすっきり保ちながら補足を書く
- 参照: 注釈マーカーをクリックするとプレビュー小窓が開きます。
:::

## (sec-tasks)= チェックボックスとアイコン

GitHub Flavored Markdown のタスクリストに対応しています。`[ ]` や `[x]` を使用すると、カスタムアイコンで表示されます。

```md
- [ ] 未完了のタスク
- [x] 完了したタスク
```

- [ ] 未完了のタスク
- [x] 完了したタスク

テキスト中の ✅ は自動的にアイコンへ変換されます。例: ✅ 完了済みの手順

## (sec-code)= コードブロックと言語ハイライト

通常のフェンスコードブロックを利用できます。ハイライトはブラウザ標準ですが、将来的にシンタックスハイライトを導入する場合はここに追記します。

```ts
function greet(name: string) {
  console.log(`Hello, ${name}!`);
}
```

## (sec-images)= 画像と図表

画像は相対パスで参照できます。`public/` 以下に置いたリソースは `/` からのパスで読み込めます。

```md
![Docs Viewer ロゴ](./images/logo.png)
```

図や表にラベルを付けて参照する場合は、見出しやコラムと同様に `(fig-sample)=` などのラベル構文を利用してください。

## (sec-preview)= プレビュー機能とテーマ

- 参照リンクをクリックすると、小窓で対象コンテンツをプレビューできます。小窓内で別の参照を辿ると、子ウィンドウが階層的に開きます。
- プレビューモードは「フローティング」「インライン」の 2 種類で、`Preview` メニューから切り替えます。画面幅が 1280px 未満の場合は自動的にインライン表示になります。
- 右上メニューではライト / ダークテーマも切り替えられます。選択内容はローカルストレージに保存され、次回アクセス時に復元されます。

## (sec-config)= ディレクトリ設定ファイル

グループ化されたドキュメントをまとめて管理するには、ディレクトリ直下に `config.yaml` を用意します。

```yaml
title: 情報論理学入門
description: >-
  グループ全体の説明。
tags:
  - info-logic
order:
  - set-relation
  - prop-define
  - semantic-func
```

- `title` と `description` はグループ一覧ページ (`GroupLayout`) に表示されます。
- `tags` はグループ配下の各ページに適用されます。
- `order` を設定すると、ナビゲーション「前へ / 次へ」がその順序で生成されます。未指定のファイルはスラッグ昇順で自動的に補完されます。

## (sec-best-practices)= ベストプラクティス

1. ラベルは `@category-topic` のように一意な名前を付けると参照しやすくなります。
2. 長文の補足は注釈やコラムを使って本文を読みやすく保ちましょう。
3. 重要な項目は `:::column-toc` で TOC に追加すると、読者がすぐにアクセスできます。
4. ファイルをグループ化する場合は `config.yaml` を更新し、順序や説明を整備してください。

## (sec-summary)= まとめ

このチュートリアルでは、Docs Viewer で利用できる主要な記法や UI 機能を紹介しました。ラベル参照やプレビュー、Typst 数式などを組み合わせることで、複雑なドキュメントも整理しながら記述できます。疑問点や追加したい機能があれば、`memo/design-doc.md` を参照しつつ拡張してください。
